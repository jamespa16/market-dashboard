# M&A Dashboard
A real-time M&A dashboard for companies making waves in the market.
Displays upcoming acquisitions, and relevant tickers & news stories for each acqusition.

## Architecture
Simple npx tool that spins up a browser-tab with relevant information, no state in v1
Uses RSS feeds + Yahoo finance to start

## UX
Shows companies, searches for financial advisers if possible, merger date
Shows a breakdown of m&a made by a specific company or financial adviser
Shows private equity stakes for companies where available
